What's inside

Made for reading on paper

Every word, in order

The text is reproduced from the published pages without summarising or rewriting. A check found all 1,065,344 source characters in the PDFs, in source order.

Nothing left folded

Everything the site hides behind a click is printed open: 86 deep dives, 91 challenges with 154 solution blocks, 47 hints, and the files of every example, including those the site never shows as tabs.

Live examples, run for real

All 744 sandboxes were built from their original files with the site's React version and run in Chrome. 1,144 print walkthroughs show BEFORE, ACTION and AFTER, from real screenshots.

Original figures

The 93 illustrations and diagrams are the original image files from react.dev, in light mode, never redrawn, each with a SHA-256 checksum in the manifest.

Typeset for print

A4 with mirrored margins for binding, 11.5 pt text, 10 pt code with syntax colour, line numbers that are not copied with the code, and running heads.

Easy to navigate

Contents, bookmarks, 5,048 working internal links, page numbers after cross-references (even into other volumes), and a 31-page master index of articles, topics and APIs.

Questions

Good to know

Is this official?

No. It is an unofficial compilation, not produced, reviewed or endorsed by Meta or the React team. The documentation itself is the work of Meta Platforms, Inc. and the react.dev contributors; the person who compiled this edition is not its author.

Which version of React does it cover?

The site as it stood on 25 November 2026, labelled react@19.3. The examples were run with React 19.3.0-canary-f1f7ed2a-20260904, the version the site's sandboxes use. Repository commit 15653c0f9b95.

May I print and share it?

Yes. The documentation is licensed under Creative Commons Attribution 4.0 (CC BY 4.0); keep the attribution that every volume carries. React and the React logo are trademarks of Meta Platforms, Inc.; the licence grants no trademark rights.

What was left out?

The blog, community pages, translations and older-version archives; links to them are kept. Everything in the Learn and Reference navigation is included: 181 articles.

How were the example screenshots made?

Each example was rebuilt from its original files with the same React version and run in headless Chrome. The runner found the real controls (buttons, fields, check boxes, lists), reset the example before each scenario, performed the action and captured the result. Nothing was drawn or edited.

Is there an index?

Yes: the master index lists all 181 articles, 1,460 section topics and 106 APIs (hooks, components, functions, directives, compiler options and lint rules) with volume·page references, such as 3·145 for Volume 3, page 145. It is also the last part of the complete edition, where every reference is a link.

Can I rebuild it myself?

Yes: the scripts are in the repository, and the source package holds the snapshot and run records.
